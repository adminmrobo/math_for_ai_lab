### 5-2. 연결 고리 14개
페이지에서 "연결 고리" 상자로 넣고, 0장·16장 관계 지도에서 선으로 그린다. 다른 부로 넘어가는 고리는 해당 부 페이지로 바로 가는 링크를 단다.

| # | 연결(장) | 한 줄 설명 | AI에서 |
|---|---|---|---|
| L1 | 3 내적 → 4 행렬곱 | 행렬곱은 내적을 여러 번 한 것 | 신경망 한 층 = Wx + b |
| L2 | 3 코사인 ↔ 7 상관계수 | **상관계수는 평균을 뺀 두 벡터의 코사인**과 같다(원자료 숫자로 0.775 일치 확인) | 추천 시스템의 "취향 닮음" |
| L3 | 3 노름 ↔ 6 표준편차 | 표준편차 = 평균을 뺀 벡터의 길이 ÷ √n | 거리 기반 모델(kNN·군집) |
| L4 | 6 분산 → 7 공분산 → 8 PCA | 한 변수의 흩어짐 → 두 변수의 함께 움직임 → 공분산 행렬의 고유벡터 | 차원 축소 |
| L5 | 4 전치·역행렬 → 5 정규방정식 | β = (XᵀX)⁻¹Xᵀy 는 4장 연산만으로 쓴 식 | 선형회귀 |
| L6 | 7 높은 상관 → 5 det≈0 → 4 단위행렬 I | 겹치는 특성이 많으면 역행렬이 불안정 → λI를 더해 살림 | **릿지 회귀** (XᵀX + λI)⁻¹ |
| L7 | 5 정규방정식 ↔ 14 경사하강법 | 같은 답을 "한 번에 풀기" vs "조금씩 내려가기" | 데이터가 크면 경사하강법 |
| L8 | 9 곱셈 규칙 ↔ 13 연쇄 법칙 | 확률도 미분도 "단계별로 곱한다" | 언어모델 문장 확률 / 역전파 |
| L9 | 11 정규분포 → 오차 제곱 손실 | 오차가 정규분포라고 보면 "제곱 오차 최소화"가 나온다 | 회귀 손실 MSE |
| L10 | 11 베르누이 → 12 교차 엔트로피 | 맞다/아니다 확률을 그대로 점수로 | 분류 손실, LLM 학습 손실 |
| L11 | 1 지수·치역 → 9 확률 범위 | e^x 는 늘 양수, 시그모이드 치역은 0~1 = 확률 범위 | 소프트맥스·시그모이드 출력 |
| L12 | 13 적분 → 11 넓이 = 1 | 확률밀도 아래 넓이는 1, 구간 확률 = 넓이 | AUC |
| L13 | 8 고유값 ↔ 15 헤시안 | 손실 그릇의 곡률도 고유값으로 읽는다 — 길쭉한 그릇 = 고유값 차이가 큼 | 학습이 느린 이유, 표준화의 효과 |
| L14 | 10 사전확률 ↔ 15 규제 | 릿지 = "가중치는 0 근처일 것"이라는 사전 믿음 | 과적합 막기 |

## 6. 장별 구성

각 장 공통 틀: **질문(시아/모아) → 공식 한 장 요약(원자료) → 생선 가게에서 → AI 현장 상자 → 연결 고리 상자 → 손으로 해 보기(주판봇) → 박사 한 줄 → 실습 대시보드**

### 6-0. 장 끝 실습 대시보드 — 공통 규칙
- **위치**: 장의 맨 끝, 박사 한 줄 바로 다음. 대시보드를 끝내면 다음 장 버튼이 강조됨(잠그지 않음)
- **구성 4단**: ① 미션 한 줄(하루) → ② 조작부(슬라이더·버튼·끌기) → ③ 결과부(그래프 + 숫자 판) → ④ 판정(주판봇이 숫자로 채점, 박사 한 줄)
- **데이터**: 전 장 공통 생선 가게 데이터
- **수식 표시**: 조작할 때마다 원자료 공식에 지금 숫자가 대입된 모습을 실시간으로(예: ‖v‖ = √(3² + 4²) = 5)
- **난이도**: 미션 1(따라 하기) → 미션 2(맞혀 보기) → 미션 3(도전, 접기 상자, X1~X3 응원)
- **기록**: 장마다 별 최대 3개, 브라우저 저장(실패해도 진행에 지장 없게), 16장에서 모아 보기
- **기술**: 한 파일 HTML, 순수 자바스크립트 + 캔버스/SVG, 외부 서버 없음, 흰 배경, 손가락 조작 가능

#### 1장 — 함수: 모델은 커다란 함수다 (MATH-01)
- 생선 가게: 무게 = f(길이)
- AI 현장: 모델 = 함수, 학습 = 가중치(상수) 정하기 / 입력은 변하고 학습이 끝난 가중치는 고정 / 선형(선형회귀)·2차(손실 그릇)·비선형(시그모이드·ReLU) / 정의역·치역 → 픽셀 0~255를 0~1로, 시그모이드 출력 0~1
- 연결 고리: → 2장, → 13장, L11
- **대시보드 「함수 기계」**: 함수 종류·a·b 슬라이더 → 입력→출력 표와 그래프 / 미션: 농어 5마리 무게에 가장 가까운 직선(오차 합 기준)

#### 2장 — 행렬: 데이터를 담는 표 (MATH-02)
- 생선 가게: 생선 3마리 × (길이·무게·높이) = 3×3 행렬
- AI 현장: 데이터셋 X = (샘플 수 × 특성 수) / 흑백 사진 = 행렬, 컬러 = 텐서 / 대각행렬 = 특성별 크기 조절, 단위행렬 = 아무것도 안 바꾸는 변환(잔차 연결의 발상)
- 연결 고리: → 3·4장, 텐서 연구실
- **대시보드 「생선 표 만들기」**: 생선을 끌어 표에 넣기, 특성 켜고 끄기 → 행렬 모양이 바로 바뀜 / 미션: 생선 4마리 × 특성 2개 만들고 모양 말하기

#### 3장 — 벡터 연산: 닮음과 거리 (MATH-03)
- 생선 가게: 생선 A와 B는 얼마나 닮았나 — 거리와 각도 두 가지로
- AI 현장: 임베딩 + 코사인 유사도로 검색(RAG)·추천 / 노름 → kNN·K-평균, 릿지의 L2 벌점 / 직교 = 서로 상관없는 정보 / 경사하강 한 걸음 θ − α∇f = 벡터 뺄셈과 스칼라 곱
- 연결 고리: L1, L2, L3, → 14장
- **대시보드 「닮은 생선 찾기」**: 화살표 두 개 끌기 → 노름·내적·각도·코사인 / 미션: 가장 닮은 생선 고르기 — 거리 기준과 코사인 기준 답이 다를 때 이유

#### 4장 — 행렬 연산: 한 번에 수백 마리 계산 (MATH-04)
- 생선 가게: 300마리 × 가중치 → 예측 300개를 곱셈 한 번으로
- AI 현장: 신경망 한 층 = 입력 × 가중치 + 치우침, GPU는 행렬곱 전용 기계 / (m×n)(n×p) 규칙 = 모양 오류의 정체 / 전치 → 어텐션 QKᵀ / 역행렬·행렬식은 5장으로

- **대시보드 「행렬곱 공장」**: 가중치 값·모양 바꾸기 → 예측 300개 변화, 모양이 안 맞으면 빨간 경고 / 미션: 모양 오류 고치기, 예측 평균을 목표 근처로

#### 5장 — 연립방정식: 답을 한 번에 풀기 (MATH-05)
- 생선 가게: 길이→무게 직선을 정규방정식으로
- AI 현장: β = (XᵀX)⁻¹Xᵀy / 해가 무수히 많음 = 특성이 데이터보다 많을 때 → 규제 필요 / 해가 없음 → 최소제곱("가장 덜 틀린 답")

### ■ 2부 `part2.html` — 데이터를 읽고, 불확실성을 말하기

#### 6장 — 통계 기초: 데이터 들여다보기 (MATH-08)
- 생선 가게: 농어 길이의 평균·중앙값·사분위, 상자 그림으로 이상한 생선 찾기
- AI 현장: 이상치에 끌려가는 평균 → 학습 전 처리 / 표준화(z점수) → 손실 그릇이 둥글어져 학습이 빨라짐(좌표축 위의 그릇) / 배치 정규화 / 평가 지표(MSE·MAE)

- **대시보드 「생선 통계판」**: 이상한 생선 넣고 빼기, 표준화 켜고 끄기 / 미션: 이상치를 넣었을 때 평균이 얼마나 움직이는지 맞히기

#### 7장 — 상관·공분산: 겹치는 정보 찾기 (MATH-10)
- 생선 가게: 길이와 높이 상관 0.9 이상 → 겹치는 정보
- AI 현장: 특성 선택 / 다중공선성 → L6 / 협업 필터링(피어슨) / 공분산 행렬 → 8장 / 상관 ≠ 인과(AI 판단 코너)
- 연결 고리: L2, L4, L6
- **대시보드 「겹치는 정보 찾기」**: 특성 두 개 고르기, 점 끌기 → 산점도·공분산·상관계수·평균 뺀 코사인 나란히 / 미션: 상관 0.9 이상인 쌍 찾아 하나 빼기, 상관 = 코사인 확인

#### 8장 — 고유값·PCA: 가장 넓게 퍼진 방향 (보강 A)
- 질문(모아): "길이랑 높이가 겹친다면, 둘을 하나로 합칠 수는 없어요?"
- 핵심 한 줄: 공분산 행렬을 곱해도 **방향이 안 바뀌고 길이만 바뀌는 화살표**가 고유벡터, 늘어나는 배율이 고유값. 가장 큰 고유값의 방향 = 데이터가 가장 넓게 퍼진 방향
- 공식 한 장(새로 만듦): Av = λv / 공분산 행렬의 고유값 합 = 전체 분산 / 설명된 분산 비율 = λ₁ ÷ (λ₁ + λ₂ + …)
- 생선 가게: 길이·높이 두 특성 → 첫 번째 주성분 하나로 "생선 크기" 특성을 만들고, 정보가 얼마나 남는지(예: 95%)
- AI 현장: 차원 축소·시각화(수백 차원 임베딩을 2차원 지도로) / 잡음 제거 / 얼굴 인식의 고유 얼굴 / 추천 시스템의 행렬 분해(SVD, 접기 상자) / 비지도학습 연결
- 연결 고리: L4, L13, 비지도학습(unsupervised_fish_lab), 유클리드 공간
- **대시보드 「방향 돌리기」**: 생선 점구름 위 화살표를 돌리면 그 방향으로 그림자(투영)가 생기고 그림자의 퍼짐이 숫자로 / "고유벡터 보기" 버튼 / 미션: 퍼짐이 가장 큰 방향을 손으로 찾고 고유벡터와 비교, 정보 몇 %가 남는지 맞히기

#### 9장 — 확률 기초: "아마도"를 숫자로 (MATH-06)
- 생선 가게: 오늘 들어온 생선 중 도미일 확률
- AI 현장: 분류 출력 = 확률, 합 1 → 소프트맥스 / 여사건 1 − p / 독립 가정 → 나이브 베이즈 / 드롭아웃
- 연결 고리: L8, L11, → 10장
- **대시보드 「확률 통」**: 도미·빙어 수 조절, 뽑기 1번·100번·1만 번 → 뽑은 비율이 이론 확률로 다가감 / 미션: 여사건·합집합 확률을 먼저 맞히고 뽑기로 검산

#### 10장 — 조건부 확률·베이즈: 증거로 생각 고치기 (MATH-07)
- 생선 가게: "지느러미가 붉다"는 증거가 나왔을 때 도미일 확률
- AI 현장: 스팸 필터·나이브 베이즈 / **정확도 99%인데 실제 환자 확률 16.7%** → 정밀도·재현율 / 언어모델 = P(다음 단어 | 앞 단어들) / 사전확률과 릿지(L14, 접기 상자)
- 연결 고리: L8, L14, 베이지안 통계 연구실
- **대시보드 「베이즈 검사소」**: 유병률·정확도·위양성 슬라이더 → 1,000명 점그림 / 미션: 16.7% 재현, 진짜 비율 50%를 넘기는 조건 찾기

#### 11장 — 확률분포: 데이터의 모양 (MATH-09)
- 생선 가게: 농어 길이(정규), 하루 손님 수(포아송), 손님 사이 간격(지수)
- AI 현장: 정규 → 가중치 초기화·확산 모델 잡음·회귀 오차 가정 / 베르누이·이항 → 이진 분류·A/B 테스트 / 포아송 → 수요 예측 / 지수 → 설비 고장 간격(예지 보전) / 균등 → 무작위 초기화
- 연결 고리: L9, L10, L12, 확률 분포 도감·확률분포 딕셔너리로 깊이 보내기
- **대시보드 「분포 맞추기」**: 분포 고르기, 모수 슬라이더 → 실제 데이터 막대 위에 곡선, 구간 넓이 / 미션: 농어 길이에 맞는 분포·모수 찾기

#### 12장 — 정보이론: 놀람의 크기와 틀린 정도 (보강 B)
- 질문(시아): "모델이 '도미 87%'라고 했는데 빙어였어요. 얼마나 틀린 거예요?"
- 핵심 한 줄: 드문 일이 일어나면 많이 놀란다. **놀람 = −log(확률)**. 평균 놀람이 엔트로피, 모델이 예측한 확률로 잰 놀람이 교차 엔트로피
- 공식 한 장(새로 만듦): 정보량 −log p / 엔트로피 H = −Σ p log p / 교차 엔트로피 −Σ p log q / KL 발산 = 교차 엔트로피 − 엔트로피 (≥ 0)
- 생선 가게: 도미·빙어 반반이면 엔트로피 1비트, 도미만 들어오면 0 — "오늘 무슨 생선일지 모르는 정도"
- AI 현장: 분류 모델과 LLM의 학습 손실 = 교차 엔트로피 / 정답에 1%만 줬을 때 손실이 크게 뛰는 이유(log의 모양) / 결정 나무의 분할 기준(정보 이득) / 지식 증류·확산·VAE의 KL / LLM의 퍼플렉시티 = 평균 놀람을 "몇 개 중에 고르는 정도"로 바꾼 값
- 연결 고리: L10, 1장(ln 함수), 13장(로그 손실 미분이 간단한 이유), LLM 공식 시리즈
- **대시보드 「놀람 저울」**: 정답 생선 고정, 모델이 각 생선에 주는 확률 막대를 끌기 → 교차 엔트로피 손실 실시간 / 미션: 손실 0.1 아래로 만들기, 정답 확률 0.01일 때 손실 보기, 엔트로피가 가장 큰 생선 구성 찾기
- 2부 끝: "3부로" 버튼 — "이제 이 손실을 줄이는 법을 배웁니다"

#### 13장 — 미적분 기초: 얼마나 빨리 변하나 (MATH-11)
- 생선 가게: 기울기를 조금 바꾸면 오차가 얼마나 변하나
- AI 현장: 미분 = 손실의 기울기 / **연쇄 법칙 = 역전파의 전부** / e^x·ln x 미분 → 소프트맥스+교차 엔트로피 기울기가 "예측 − 정답"으로 간단해짐 / 적분 → 확률 넓이·AUC

#### 14장 — 편미분·그래디언트: 조금씩 내려가기 (MATH-12)
- 생선 가게: 기울기·절편 두 가중치를 동시에 고치기
- AI 현장: 편미분 = 가중치 하나하나의 책임 몫 / 경사하강법·학습률 / 접평면 → 한 걸음을 작게 하는 이유 / 가중치가 수억 개면 그래디언트 원소도 수억 개 — 원리는 같다 / 2차 편미분 → 15장
- 연결 고리: L7, 좌표축 위의 그릇·∇ 특별편
- **대시보드 「등고선 내려가기」**: 출발점, 학습률 α, 표준화 켜고 끄기 → 공의 경로·단계별 손실 / 미션: 30걸음 안에 바닥, α가 크면 튀는 것 확인, 5장 정규방정식 답과 같은 곳인지 확인

#### 15장 — 최적화: 더 잘, 더 빨리 내려가기 (보강 C)
- 질문(모아): "그냥 내려가면 되는데 왜 방법이 이렇게 많아요?"
- 핵심 한 줄: 그릇 모양이 고르면 아무 방법으로도 내려가지만, **길쭉하거나 울퉁불퉁하면 걷는 방법이 결과를 바꾼다**
- 공식 한 장(새로 만듦): 볼록 함수(그릇이 하나뿐 → 바닥도 하나) / 헤시안(2차 편미분 표) → 곡률 / 모멘텀 v ← βv + ∇f / Adam = 모멘텀 + 원소별 걸음 조절 / 규제 손실 + λ‖w‖² / 미니배치 확률적 경사하강
- 생선 가게: 길이(cm)와 무게(g)처럼 크기가 다른 특성 → 길쭉한 그릇 → 경사하강이 지그재그
- AI 현장: 딥러닝 기본값 Adam / 학습률 스케줄(처음엔 크게, 나중엔 작게) / 미니배치 = 데이터 일부로 기울기를 어림 / 볼록이 아닌 신경망 손실 — 지역 바닥·안장점 / 규제·조기 종료로 과적합 막기
- 연결 고리: L13(헤시안 고유값), L14, 6장(표준화), 좌표축 위의 그릇 1~3편, 라그랑지안·해밀토니안 특집(모멘텀의 물리 비유)
- **대시보드 「옵티마이저 경주」**: 그릇 모양 고르기(둥근·길쭉·울퉁불퉁·안장), 경사하강·모멘텀·Adam 동시 출발, 학습률·λ 슬라이더 / 미션: 길쭉한 그릇에서 세 방법 순위 맞히기, 안장점에서 탈출하는 방법 찾기
- 시아 vs 모아 짧은 대결: 시아는 경사하강, 모아는 Adam — 하루 심판

#### 16장 — 실전 연습장: 생선 가게 시뮬레이터 (종합판)
- 1~15장 대시보드 부품을 한 화면에 이어 붙임:
  특성 고르기(7장) → PCA로 줄이기 켜고 끄기(8장) → 표준화(6장) → 정규방정식 vs 경사하강 vs Adam 경주(5·14·15장) → 분류 확률·교차 엔트로피(12장) → 임계값과 위양성(10장)
