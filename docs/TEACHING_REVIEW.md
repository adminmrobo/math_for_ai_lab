# 교수법 자가 채점 — 인공지능을 위한 수학 (v1.0)

독자 진단(작업 메모): 대상 독자를 따로 정하지 않아 혼합형으로 가정했다. 수식 앞에 말·그림·작은 숫자를 먼저 두고, 해석 문장 연습은 각 장 끝에 둔다.

|---|---|---|---|---|
| P1 | 원리 먼저 | 3 | 모든 장이 박사의 상황 질문 → "왜 이 개념이 필요한가"(문제·앞 장의 한계·해법) → 수식 순서 | — |
| P2 | 과정을 한 번은 보여 주기 | 3 | 장마다 "숫자로 한 번 해 보기" 3줄, 원자료 예제를 손계산으로. 53개 값 검산(build/check_numbers.py) | — |
| P3 | 기호는 말로 먼저 | 3 | 수식 상자마다 조수 질문 → "말로 하면" → 식 조각 표(읽는 법과 뜻), 0~1부 머리에 기호·약어 풀이 | — |

## v1.1 다시 채점
대결 3개(조수 숫자 발표·박사 판정), 장마다 퀴즈 2문항(1부 10·2부 14·3부 8문항, 계산 문항 포함), 용어 말풍선, 비유의 한계, 현장에 옮기면 상자, 실전 연습장 세 현장을 더했다. P1~P7 모두 3점 유지, 합계 21 / 21. 남은 과제: 12장 밀도, 장 첫 대화 줄이기(2차 감사 7순위).
