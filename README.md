# 인공지능을 위한 수학 — 공식 12장이 모델 하나가 되기까지

공식을 따로 외우지 않습니다. **생선 가게 AI 모델 하나**를 처음부터 끝까지 만들면서, 공식 하나하나가 모델의 어느 부품이 되는지 따라가는 연구실 해설입니다. 장마다 끝에 **실습 대시보드**가 있어 배운 것을 직접 만져 봅니다.

- 공개 주소: https://adminmrobo.github.io/math_for_ai_lab/
- 글 · 안상선 ((주)M-Robo 대표) · [저자 소개](https://adminmrobo.github.io/who_am_i/who_am_i.html)
- 원자료: 인포그래픽 「Mathematics for Machine Learning — Complete Notes」 표지와 MATH-01~12 (제작자 표기 확인 중). 표지가 약속했지만 카드에 없던 **최적화·PCA**, 그리고 AI 손실의 바탕인 **정보이론**을 보강 A~C로 새로 썼습니다.

## 팀장용 한 장 요약
| 모델의 동작 | 배우는 수학 | 업무에서 읽게 되는 것 |
|---|---|---|
| ① 담기 | 함수·행렬 | 데이터 표의 모양, "모양이 안 맞는다" 오류 |
| ② 계산하기 | 벡터·행렬 연산·연립방정식 | 검색·추천의 유사도, 회귀 계수가 흔들리는 이유 |
| ③ 재기 | 통계·상관·PCA·확률·베이즈·분포·정보이론 | 이상치, 겹치는 항목, 위양성, 분류 손실 |
| ④ 고치기 | 미분·그래디언트·최적화 | 학습률, "학습이 안 돼요"의 원인 |

실전 연습장의 세 현장은 모두 "가장 그럴듯한 숫자 하나가 아니라 흩어짐과 실수의 값까지 넣어 결정한다"는 한 문장으로 묶입니다. 공장은 비용으로 임계값을, 콜센터는 분포의 꼬리로 인원을, 광고 분석은 검증 오차로 λ를 정합니다.

등장인물: 시아·모아가 묻고 조수 하루가 답합니다. 초파리 연구원과 주판봇이 실습을 돕고, 박사가 장마다 정리합니다. 방청석에는 X1~X3이 있습니다.

## 강의에서 쓸 때 — 실습 대시보드 미션 정답 조작
미션은 자동으로 채점되고 별은 브라우저에만 저장됩니다. 학생이 막혔을 때 보여 줄 정답 조작입니다(스크립트로 판정을 확인한 값).

| 장 | 대시보드 | 미션 1 | 미션 2 | 미션 3 (도전) |
|---|---|---|---|---|
| 0 | 수학 지도 탐험 | 카드 아무거나 | 카드 2~3장 | 카드 15장 모두 |
| 1 | 함수 기계 | 네 모양 모두 누르기 | 직선 a = 2.6, b = −4.9 (합 1.7) | 2차 a = 0.5, b = −1.7 (합 1.0) |
| 2 | 생선 표 만들기 | 생선 1 + 특성 1 | 생선 4 × 특성 2 | 생선 3 × 특성 3 |
| 3 | 닮은 생선 찾기 | a = (4, 1), b = (−1, 4) | a = (6, 2), b = (3, 1) | a = (3, 4) |
| 4 | 행렬곱 공장 | 표의 한 줄 누르기 | 3 × 1 → 2 × 1 | w₁ = 26, w₂ = 0, b = −460 (62.8g) |
| 5 | 한 번에 풀기 | 점 하나 끌기 | "한 세로줄에 모으기" (det 0.14) | 그 상태에서 λ = 0.5 (기울기 1.04) |
| 6 | 생선 통계판 | 150cm 넣기 | 표준화 | 150cm + IQR 울타리 |
| 7 | 겹치는 정보 찾기 | 길이-높이 | 길이-입고 날짜 | 평균 빼고 코사인 |
| 8 | 방향 돌리기 | 45° | 고유벡터 보기 | 135° |
| 9 | 확률 통 | 1만 번 | P(빙어) = 0.455 | 0.298 |
| 10 | 베이즈 검사소 | 원자료 숫자 넣기 | 유병률 30% | 유병률 1%, 위양성률 0.5% |
| 11 | 분포 맞추기 | 길이·정규 μ = 29, σ = 9 | 손님 수·포아송 λ = 2.9 | 간격·지수 λ = 0.06 |
| 12 | 놀람 저울 | 도미 점수 5, 나머지 0 | 도미 점수 −5 | 셋 다 0 |
| 13 | 기울기 돋보기 | h 0.01 | w = 3 | 넓이 칠하기, 끝 = 1 |
| 14 | 등고선 내려가기 | 표준화 켜고 α = 0.6, 30걸음 | 표준화 끄고 같은 α로 30걸음 | 미션 1·2를 같은 α로 |
| 15 | 옵티마이저 경주 | 아무 그릇 출발 | 안장점 출발 | 길쭉한 그릇 α = 0.09 |
| 16 | 생선 가게 종합 | 특성 길이³ (검증 25.4g) | 길이³ + 표준화 + 경사하강 | 같은 설정(검증 25.4g) |
| 실전 | 불량 검사 공장 | 임계값 약 1.8 (불량률 2%) | 정확도 최고 임계값 약 2.85 | 불량률을 바꾸고 다시 최소 찾기 |
| 실전 | 콜센터 | 비용 최소 인원 | λ = 12에서 상담원 4명(다 받을 확률 58%) | λ를 바꾸고 다시 최소 찾기 |
| 실전 | 광고 예산 분석 | 검증 오차 최소 λ | 겹침 0.95 이상, λ = 0 | 겹침 0.5 이하로 낮추고 다시 찾기 |
