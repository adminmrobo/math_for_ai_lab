수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 σ² = (1/n)Σ(xᵢ − μ)²… 왜 굳이 빼고, 제곱하고, 평균을 내요?
말로 하면 — 각 값이 평균에서 얼마나 떨어졌는지(빼기)를 재고, +와 −가 서로 지우지 않게 제곱한 뒤, 평균을 냅니다. 그게 분산이고, 단위를 되돌리려고 루트를 씌운 것이 표준편차입니다.
x̄ = Σxᵢ / n , σ² = (1/n) Σ(xᵢ − μ)² , σ = √σ² , z = (x − μ) / σ
식 조각읽는 법과 뜻
x̄, μ엑스 바, 뮤 — 평균
σ², σ시그마 제곱, 시그마 — 분산, 표준편차
Q1, Q3제1·제3 사분위수 — 아래에서 25%, 75% 자리
IQRQ3 − Q1 — 가운데 50%가 퍼진 폭
zz점수 — 평균에서 표준편차 몇 개만큼 떨어졌나
숫자로 한 번 해 보기
원자료 예제: 2, 4, 6, 8, 10 → 평균 6, 분산 (16 + 4 + 0 + 4 + 16)/5 = 8, 표준편차 √8 ≈ 2.828.
원자료 6번 표: 1, 2, 2, 3, 100 → 평균 21.6, 중앙값 2. 100 하나가 평균을 끌어올렸습니다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 r = Cov(X, Y) / (σₓ σᵧ)에서 왜 표준편차 두 개로 나눠요?
말로 하면 — 공분산은 단위(cm × g 같은)에 따라 크기가 바뀝니다. 각자의 표준편차로 나누면 단위가 사라지고 −1과 1 사이로 들어옵니다. 그것이 상관계수 r입니다.
Cov(X, Y) = (1/n) Σ(xᵢ − x̄)(yᵢ − ȳ) , r = Cov(X, Y) / (σₓ σᵧ) , −1 ≤ r ≤ 1
식 조각읽는 법과 뜻
Cov(X, Y)공분산 — 함께 움직인 정도. 부호가 방향
r상관계수 — 단위 없는 세기. ±1에 가까울수록 직선에 가깝다
σₓ, σᵧ각 변수의 표준편차(6장)
r = 0직선 관계가 없음 (곡선 관계는 있을 수 있음)
숫자로 한 번 해 보기
원자료 예제: X = 1, 2, 3, 4, 5 / Y = 2, 4, 5, 4, 5. 평균 3과 4.
벗어난 양의 곱: (−2)(−2) + (−1)(0) + 0 + (1)(0) + (2)(1) = 4 + 0 + 0 + 0 + 2 = 6 → Cov = 6/5 = 1.2.
σₓ = √2 ≈ 1.414, σᵧ = √1.2 ≈ 1.095 → r = 1.2 / 1.549 ≈ 0.775. 평균을 뺀 두 벡터 (−2, −1, 0, 1, 2), (−2, 0, 1, 0, 1)의 코사인도 6 / (√10 × √6) ≈ 0.775로 같습니다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 Av = λv… 행렬을 곱했는데 숫자 하나 곱한 거랑 같다는 게 무슨 뜻이에요?
말로 하면 — 대부분의 화살표는 행렬을 곱하면 방향이 꺾입니다. 그런데 어떤 화살표는 방향은 그대로 두고 길이만 늘어나거나 줄어듭니다. 그 화살표가 고유벡터 v, 늘어나는 배율이 고유값 λ입니다.
A v = λ v , 설명된 분산 비율 = λ₁ / (λ₁ + λ₂ + …)
식 조각읽는 법과 뜻
A공분산 행렬 — 특성 쌍마다 공분산을 모은 정사각행렬(7장)
v고유벡터 — 곱해도 방향이 안 바뀌는 화살표 = 데이터가 퍼진 방향
λ람다, 고유값 — 그 방향으로 퍼진 양(분산)
λ₁ + λ₂전체 퍼짐 = 각 특성 분산의 합
숫자로 한 번 해 보기
표준화한 길이·높이의 공분산 행렬은 [1 r ; r 1]입니다(r = 0.992).
고유값은 1 + r = 1.992와 1 − r = 0.008입니다. 고유벡터는 (1, 1)/√2와 (−1, 1)/√2. 손으로 확인: [1 r ; r 1](1, 1) = (1 + r, r + 1) = (1 + r)(1, 1). 방향이 그대로입니다.
첫 방향 하나가 1.992 / 2 = 99.6%의 퍼짐을 담습니다. 특성 2개를 1개로 줄여도 정보의 0.4%만 잃습니다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 P(A ∪ B) = P(A) + P(B) − P(A ∩ B)에서 왜 하나를 빼요?
말로 하면 — A와 B를 그냥 더하면 둘 다에 속하는 부분(A ∩ B)을 두 번 셉니다. 그래서 한 번 빼 줍니다. 벤 다이어그램의 겹친 부분입니다.
P(E) = 원하는 경우 수 / 전체 경우 수 , P(Eᶜ) = 1 − P(E) , 독립이면 P(A ∩ B) = P(A) × P(B)
식 조각읽는 법과 뜻
S표본공간 — 가능한 결과 전체
P(E)사건 E의 확률, 0 이상 1 이하
Eᶜ여사건 — E가 아닌 것
∪, ∩또는(합집합), 그리고(교집합)
독립한쪽 결과가 다른 쪽 확률을 바꾸지 않음
숫자로 한 번 해 보기
원자료 예제: 주사위 A = {1, 2, 3}, B = {2, 4, 6}, A ∩ B = {2}. P(A ∪ B) = 3/6 + 3/6 − 1/6 = 5/6.

P(A)사전확률 — 증거 전의 믿음 (유병률)

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 H = −Σ p log p… 확률에 로그를 씌우고 왜 또 마이너스를 붙여요?
말로 하면 — 확률은 1보다 작아서 로그를 씌우면 음수가 됩니다. 마이너스를 붙여 양수로 바꾼 것이 '놀람'입니다. 그 놀람을 확률로 가중 평균한 것이 엔트로피, 정답 분포 p와 모델 분포 q로 섞어 잰 것이 교차 엔트로피입니다.
놀람 = −log p , 엔트로피 H(p) = −Σ p log p , 교차 엔트로피 H(p, q) = −Σ p log q , KL(p‖q) = H(p, q) − H(p) ≥ 0

H(p, q)교차 엔트로피 — 정답 p를 모델 q로 예측했을 때의 평균 놀람 = 분류 손실

도미·빙어가 반반이면 H = −(0.5 log₂0.5 + 0.5 log₂0.5) = 1비트. 도미만 오면 H = 0 (전혀 놀랍지 않음).
정답이 도미이고 모델이 도미에 0.87을 줬다면 손실 = −ln 0.87 ≈ 0.139. 0.51을 줬다면 −ln 0.51 ≈ 0.673.
